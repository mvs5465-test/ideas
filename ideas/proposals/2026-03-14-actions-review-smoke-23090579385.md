# actions-review-smoke

## Summary

This proposal exists to create a pull request authored by GitHub Actions so review submission can be tested against a non-user actor.

## Status

Proposed

## Problem

Review automation needs a safe target PR that is not opened by the repository owner account.

## Proposal

Add this temporary proposal file through a workflow-authored branch and PR.

## Scope

In scope: creating one small PR for review testing.
Out of scope: shipping product behavior or merging the resulting PR.

## Risks And Tradeoffs

The repo accumulates a disposable proposal file and PR metadata that should be cleaned up after testing.

## Alternatives Considered

Use a GitHub App token. That is more flexible but unnecessary when the built-in Actions token is already allowed to open PRs.

## Rollout Plan

Trigger the workflow manually, verify the PR author is `github-actions[bot]`, run the review test, then close the PR when finished.

## Success Criteria

A pull request is opened from a workflow-created branch and the PR author is not `mvs5465`.
