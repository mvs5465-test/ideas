# ideas

Collaborative idea proposals via pull requests.

## How This Repo Works

1. Open a PR that adds or updates an idea document under `ideas/proposals/`.
2. Use the PR template and keep the reviewer instructions block at the top.
3. Reviewers approve or request changes.
4. Approved ideas are merged with squash merge.

## Layout

- `ideas/proposals/`: concrete idea proposals
- `ideas/templates/`: proposal templates
- `AGENTS.md`: instructions for AI agents contributing in this repo

## Quick Start

1. Copy `ideas/templates/feature-idea.md` into `ideas/proposals/` with a clear filename.
2. Fill each section with concrete details and tradeoffs.
3. Open a PR and request review.
